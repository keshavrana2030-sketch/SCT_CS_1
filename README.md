# SCT_CS_1 - Caesar Cipher Encryption & Decryption

##  Objective
The objective of this project is to implement the Caesar Cipher algorithm to encrypt and decrypt text messages using a user-defined shift key.
This project helps in understanding the fundamentals of classical cryptography and secure communication techniques.
---
### Features Included

•	Encrypt text using a custom shift value.
•	Decrypt encrypted text using the same key.
•	Menu-driven interface for easy interaction.
•	Supports uppercase and lowercase letters.
•	Preserves spaces, numbers, and special characters.
•	Brute-force attack demonstration.

---

##  Tools & Libraries Used

•	Python 3
•	Visual Studio Code
•	Built-in Python Functions
•	ASCII Character Encoding


---

---

##  Key Insights

* •	Caesar Cipher is one of the simplest classical encryption techniques.
•	Encryption converts readable text into ciphertext using a shift key.
•	Decryption restores the original message using the same key.
•	The cipher is vulnerable to brute-force attacks because it has only 25 possible keys.
•	This project demonstrates both encryption and cryptanalysis concepts.

---

##  Conclusion

This project provides a practical introduction to cryptography by implementing Caesar Cipher encryption and decryption in Python. It demonstrates how messages can be secured using simple encryption techniques and highlights the limitations of classical ciphers against brute-force attacks.
